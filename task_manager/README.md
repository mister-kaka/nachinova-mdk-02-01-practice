# Task Manager

Учебное приложение «Список задач» (SQLite + Flask).
Сейчас готово: практические работы 1-7.

## Файлы

- `init_db.py` - создаёт базу `app.db` и таблицу `tasks`
- `check_db.py` - показывает, какие таблицы есть в базе
- `crud_console.py` - консольное приложение: показать задачи, добавить, отметить выполненной, удалить
- `app.py` - веб-приложение на Flask
- `static/hourglass.webp` - картинка для страницы
- `templates/index.html` - страница со списком задач

## Запуск

```
python init_db.py
python crud_console.py   # консольная версия
pip install flask
python app.py
```

Сайт открывается по адресу http://127.0.0.1:5000. Консольная версия и сайт работают с одной базой `app.db`.
