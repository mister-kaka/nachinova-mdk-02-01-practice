# Task Manager

Учебное приложение «Список задач» (SQLite + Flask). 
Сейчас готово: практические работы 1-2.

## Файлы

- `init_db.py` - создаёт базу `app.db` и таблицу `tasks`
- `check_db.py` - показывает, какие таблицы есть в базе
- `crud_console.py` - консольное приложение: показать задачи, добавить, отметить выполненной, удалить

## Запуск

```
python init_db.py
python crud_console.py   # консольная версия
```

## Что добавлялось по работам

| Работа | Что сделано |
|--------|-------------|
| ПР1 | база SQLite, таблица `tasks`, проверка таблицы |
| ПР2 | консольное приложение: чтение, добавление, отметка, удаление |

Отчёты по работам лежат в папке `reports` (в корне репозитория).
