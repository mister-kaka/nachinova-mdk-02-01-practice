Часть A. Тест

1. Что произойдёт, если после cursor.execute("INSERT ...") не вызвать conn.commit()?
б) Данные не будут записаны на диск и пропадут при закрытии соединения

2. Какой из запросов защищён от SQL-инъекции?
в) cursor.execute("INSERT INTO tasks (title) VALUES (?)", (title,))

3. Что вернёт cursor.fetchall(), если в таблице нет строк?
б) [] (пустой список)

4. Какой HTTP-метод для формы, которая создаёт новую запись?
б) POST

5. Что делает redirect(url_for('index')) после успешного POST?
б) Отправляет браузеру команду перейти на GET /

6. Зачем нужен finally: conn.close()?
б) Чтобы соединение закрылось при любом исходе, даже при ошибке

7. Что делает conn.rollback()?
в) Отменяет текущую транзакцию, изменения не попадут в базу

8. Что означает @app.route('/delete/<int:task_id>', methods=['POST'])?
а) Маршрут принимает только POST; task_id - целое число из URL

9. Что такое sqlite3.Row?
б) Обёртка над строкой результата, поля доступны по имени: row['title']

10. Открыть /toggle/5 в адресной строке, если у маршрута methods=['POST']?
в) Браузер вернёт 405 Method Not Allowed

Часть B. Практические задания

Задание 11. Анализ кода

import sqlite3

def add_task(title):
    conn = sqlite3.connect('app.db')
    cursor = conn.cursor()
    cursor.execute("INSERT INTO tasks (title) VALUES (?)", title)
    return True

Ошибка 1: вторым аргументом передана строка title. Для одного знака вопроса нужен кортеж из одного элемента (title,). Строка считается набором символов, sqlite3 даёт ProgrammingError: число значений не равно 1.
Ошибка 2: нет conn.commit(). INSERT не записывается на диск и пропадает при закрытии соединения.
Ошибка 3: соединение не закрывается. Нужен try/finally и в finally вызов conn.close(). В этом фрагменте нет except, поэтому rollback сюда ставить некуда, пока ошибка не перехватывается.

Задание 12. Дописать код

import sqlite3

def delete_task_by_id(task_id):
    conn = sqlite3.connect("app.db")
    try:
        cursor = conn.cursor()
        cursor.execute("DELETE FROM tasks WHERE id = ?", (task_id,))
        conn.commit()
        return cursor.rowcount
    except sqlite3.Error:
        conn.rollback()
        return 0
    finally:
        conn.close()

Задание 13. Мини-сценарий

Форма отправляет POST на /.

1. Браузер отправляет POST-запрос на / и передаёт поле title.
2. Flask находит маршрут index() для адреса /.
3. index() видит method POST и читает title из request.form.
4. Открывается соединение с базой.
5. Выполняется INSERT с параметром (title,).
6. При успехе вызывается commit(). При ошибке вызывается rollback(), и запись в базу не попадает.
7. Соединение закрывается в finally, и при успехе, и при ошибке.
8. redirect ведёт браузер на GET /. Пользователь видит страницу заново, уже со списком задач, включая новую.
