# Работа с файлами и сетью в bash

Скрипты практической работы по МДК 02.01 (материалы: `bash_practice.md`).

## Скрипты

- `fileinfo.sh`, `filecreate.sh`, `copybackup.sh`, `filefind.sh`, `filepermissions.sh` - работа с файлами
- `myip.sh`, `pingtest.sh`, `portscan.sh`, `download.sh`, `netstat.sh`, `dnslookup.sh`, `speedtest.sh` - работа с сетью
- `counter.sh`, `watcher.sh`, `menu.sh` - простые полезные скрипты


Скрипты запускались в ROSA Linux.

Отчёт и скриншоты: [`reports/b3_files_network`](../../reports/b3_files_network).
