# Основы bash на Ubuntu

Скрипты практической работы по МДК 02.01 (материалы: `practice_basics_syntax.md`).

## Скрипты

- `first_script.sh` - первый скрипт: приветствие, дата, пользователь
- `variables.sh` - переменные
- `ввод_данных.sh` - ввод данных с клавиатуры (read)

## Запуск

```
chmod +x имя_скрипта.sh
./имя_скрипта.sh
```

Скрипты запускались в Linux (Ubuntu).

Отчёт и скриншоты: [`reports/b0_syntax_ubuntu`](../../reports/b0_syntax_ubuntu).
