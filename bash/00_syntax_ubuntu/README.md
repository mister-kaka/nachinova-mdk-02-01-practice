# Основы bash на Ubuntu

Скрипты практической работы по МДК 02.01.

## Скрипты

- [`first_script.sh`](first_script.sh) - первый скрипт: приветствие, дата, пользователь
- [`variables.sh`](variables.sh) - переменные
- [`ввод_данных.sh`](ввод_данных.sh) - ввод данных с клавиатуры (read)
- [`базовый_if.sh`](базовый_if.sh) - условный оператор if
- [`проверка_файла.sh`](проверка_файла.sh) - проверка файла: существует ли, можно ли читать
- [`цикл_for.sh`](цикл_for.sh) - цикл for
- [`цикл_while.sh`](цикл_while.sh) - цикл while
- [`функции.sh`](функции.sh) - функции
- [`сканер_сети.sh`](сканер_сети.sh) - простой сканер портов
- [`мониторинг.sh`](мониторинг.sh) - мониторинг системы: дата, процессор, память, диск
- [`резервная_копия.sh`](резервная_копия.sh) - резервное копирование папки
- [`обновление.sh`](обновление.sh) - обновление системы (apt)
- [`обработка_ошибок.sh`](обработка_ошибок.sh) - обработка ошибок (set -e, проверка прав)
- [`отладка.sh`](отладка.sh) - отладка (set -x, set -u)
- [`оформленный_скрипт.sh`](оформленный_скрипт.sh) - скрипт с шапкой и оформлением
- [`полезные_команды.sh`](полезные_команды.sh) - примеры grep, awk, sed

Скрипты запускались в Linux (Ubuntu).
