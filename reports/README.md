## Что лежит в каждой папке

В папке одной работы обычно есть:

- **Word-отчёт** (`.docx`) - файл для сдачи / скачивания
- **Markdown-отчёт** (`.md`) - та же практическая со скриншотами, можно смотреть на GitHub без скачивания
- **`screens/`** - скриншоты к отчёту
